## О проекте

LifeBudget помогает заранее распределять деньги на повседневные потребности. Пользователь сам задаёт доход и лимиты, записывает расходы, планирует питание и покупки, а также отслеживает личные и семейные цели.

Проект создан как MVP для хакатона **Mars IT × Techstars Startup Week Tashkent** в направлении FinTech. Он предназначен для студентов, молодых специалистов и семей, которым важно понимать свой бюджет и планировать расходы.

> **Важно о ценах:** каталог содержит реальные акционные предложения Korzinka и отдельный демонстрационный каталог. Цены ингредиентов, используемые в расчёте меню, пока демонстрационные и не отражают актуальные рыночные цены.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **Бюджет** | Указать месячный доход, обязательные расходы, резерв и суммы по категориям. Записывать траты и видеть остаток. |
| **Питание** | Создать меню на 30 дней из 24 шаблонов блюд, посмотреть ингредиенты, рецепты и ориентировочную стоимость. |
| **Покупки** | Получить список на первую неделю из меню, отмечать купленное и добавлять товары вручную. |
| **Цены** | Посмотреть акции Korzinka для Ташкента и области с источником, размером упаковки и сроком действия, если он указан. |
| **Запасы** | Записывать продукты, которые уже есть дома. |
| **Копилка и семья** | Вести личные и семейные цели, отмечать пополнения и приглашать участников по коду. |
| **AI-анализ** | По запросу получить рекомендации по расходам текущего месяца и цели накопления. Требуется настройка API-ключа. |
| **Язык и интерфейс** | Использовать основные разделы на русском, узбекском или английском, переключать тему и открыть приложение на смартфоне. |

Копилка — инструмент для учёта: приложение **не хранит и не переводит реальные деньги**.

## Как работает основной сценарий

1. Зарегистрируйтесь и настройте бюджет и обязательные расходы.
2. Распределите доступные суммы по категориям и добавьте резерв.
3. Создайте меню и проверьте недельный список покупок.
4. Записывайте фактические расходы и следите за остатком.
5. Создайте личную или семейную копилку для важной цели.

## Быстрый старт

### Docker Compose

Понадобятся Docker и Docker Compose.

```bash
cp .env.example .env
```

Откройте `.env` и замените `SECRET_KEY`, а также пароль в `DATABASE_URL` и `POSTGRES_PASSWORD`. Учётные данные в URL и переменных PostgreSQL должны совпадать. Затем запустите:

```bash
docker compose up --build
```

Приложение будет доступно на **http://localhost:8080**. При первом запуске создаются таблицы, демонстрационный каталог и локальные аккаунты:

| Назначение | Логин | Пароль |
| --- | --- | --- |
| Демо-пользователь | `demo` | `LifeBudget2026!` |
| Django admin | `admin` | `LifeBudget2026!` |

Эти данные предназначены только для локальной демонстрации. Перед публичным размещением удалите демо-аккаунты или смените их пароли.

### Без Docker

Для локальной разработки без `DATABASE_URL` Django использует SQLite.

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python backend/manage.py migrate
.venv/bin/python backend/manage.py seed
.venv/bin/python backend/manage.py runserver
```

В отдельном терминале запустите frontend:

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173**. Vite перенаправляет запросы `/api/` на локальный Django-сервер.

### Проверки

```bash
# Тесты серверной логики и API
.venv/bin/python backend/manage.py test core

# Проверка конфигурации Django
.venv/bin/python backend/manage.py check

# Проверка TypeScript и production-сборка frontend
npm run build
```

## Конфигурация

Пример переменных находится в [`.env.example`](.env.example). Не добавляйте `.env` и реальные ключи в Git.

| Переменная | Назначение |
| --- | --- |
| `SECRET_KEY` | Секрет Django; для развёртывания задайте уникальное значение. |
| `DEBUG` | Режим отладки Django. Для развёртывания используйте `0`. |
| `ALLOWED_HOSTS` | Разрешённые имена хостов через запятую. |
| `DATABASE_URL` | URL подключения Django к PostgreSQL. Если не задан, используется SQLite. |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | Начальные параметры локального контейнера PostgreSQL в Compose. |
| `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY` | Адрес OpenAI-compatible API, модель и серверный ключ для анализа расходов. |

PostgreSQL в Docker хранит данные в volume `postgres_data`. Переменные `POSTGRES_*` используются для **первоначального** создания базы; их изменение не меняет пароль уже существующей роли. Специальные символы пароля в `DATABASE_URL` нужно кодировать в формате percent-encoding. Для подключения поддерживается параметр `?sslmode=require`.

При локальном запуске без Compose переменные окружения нужно задать в терминале или другим способом: Django не загружает `.env` автоматически.

## Источник цен

Раздел «Цены» получает категорию **«Суперцены недели»** из общедоступного каталога Korzinka. При посещении страницы сервер проверяет обновление не чаще раза в 6 часов; после ошибки повторная попытка доступна через 30 минут. Если источник недоступен, отображаются последние сохранённые предложения с датой загрузки.

- Акционные цены относятся к Ташкенту и Ташкентской области; условия и наличие нужно проверять в магазине.
- Цена товара показывается за размер упаковки, указанный источником.
- Цена вручную добавленного в список товара сохраняется на момент добавления.
- Акционные товары не подменяют демонстрационные цены ингредиентов в расчётах меню.

## AI-анализ расходов

В разделе бюджета можно сохранить цель и запросить анализ расходов **за текущий календарный месяц**. Перед отправкой пользователь видит, какие данные будут переданы внешнему сервису `factory.marshub.uz`, и отмечает согласие.

Итоги и срок достижения цели при заданном ежемесячном взносе рассчитываются сервером; AI формулирует рекомендации. Срок — простой арифметический расчёт, а не прогноз или гарантия. Без API-ключа функция сообщает, что не настроена. Ответы модели могут содержать ошибки.

## Семейное пространство

Создатель семьи может передать код приглашения другим зарегистрированным пользователям. Участники видят общие копилки и их пополнения; личные расходы и личные копилки остаются приватными. Код доступен создателю и может быть обновлён — старый перестанет работать.

Храните код приватно: любой его обладатель сможет присоединиться к семье. Участник может выйти из семьи; передача владения и удаление семьи через интерфейс пока не предусмотрены. Ранее сохранённая цель в бюджете показывается отдельно от новых копилок.

## Ограничения MVP

- Меню формируется по шаблонам и не является персональной медицинской или диетологической рекомендацией. Исключения задаются конкретными ингредиентами.
- Стоимость сохранённого меню фиксируется при его создании; цены меню демонстрационные.
- Полноценное сравнение альтернатив, календарь платежей и вычитание домашних запасов из списка покупок пока не реализованы.
- Названия товаров Korzinka и записи пользователя показываются на языке источника или ввода.
- Офлайн-режим PWA ограничен оболочкой: для данных нужен сервер.
- Агрегированная статистика доступна персоналу через `/api/stats/`; расчётная экономия пока не вычисляется.
- Перед публичным использованием нужны отдельная проверка безопасности, безопасные секреты и политика хранения данных.
