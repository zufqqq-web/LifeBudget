# LifeBudget

Приложение для планирования бюджета, питания и покупок. Все 100 цен в начальном каталоге вымышлены и не отражают актуальные цены. Не используйте их для реальных финансовых решений.

## Запуск через Docker Compose

```sh
cp .env.example .env
# Замените SECRET_KEY и пароль в DATABASE_URL и POSTGRES_PASSWORD в .env
docker compose up --build
```

Откройте http://localhost:8080. Демо: `demo` / `LifeBudget2026!`. Администрирование: http://localhost:8080/admin/ , `admin` / `LifeBudget2026!`. Эти аккаунты предназначены только для локальной демонстрации; перед публичным размещением удалите их или смените пароли. База PostgreSQL сохраняется в volume. Django подключается через `DATABASE_URL`; переменные `POSTGRES_DB`, `POSTGRES_USER` и `POSTGRES_PASSWORD` нужны только для первоначального создания локальной базы контейнером. Их значения должны соответствовать URL. Пароль со специальными символами в URL необходимо закодировать в формате percent-encoding. Поддерживается параметр `?sslmode=require`. Изменение переменных после первого запуска не меняет пароль уже созданной базы: для этого требуется отдельно сменить пароль роли в PostgreSQL.

## Локальная разработка

```sh
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python backend/manage.py migrate
.venv/bin/python backend/manage.py seed
.venv/bin/python backend/manage.py runserver
```

В другом терминале:

```sh
npm install
npm run dev
```

Откройте http://localhost:5173. Без `DATABASE_URL` используется локальная SQLite. Тесты: `.venv/bin/python backend/manage.py test core`; проверка сборки: `npm run build`.

## Возможности и ограничения

Регистрация и токенная авторизация, профиль, серверный расчёт бюджета, история расходов, каталог из 100 демонстрационных товаров, 30-дневное меню на основе 24 шаблонов рецептов, рецепты, список на первую неделю, запасы и обратная связь. Распределение по категориям и резерв пользователь задаёт самостоятельно; товары можно добавить в список вручную. Меню генерируется по шаблонам, а не AI, и не является индивидуальной медицинской или диетологической рекомендацией. Исключения указываются конкретными ингредиентами. Стоимость списка обновляется при изменении цен в Django admin; стоимость сохранённого меню является снимком на момент создания. Агрегированная статистика доступна администратору по `/api/stats/`; оценка экономии пока не рассчитывается и равна нулю. В настройках доступны русский, узбекский и английский языки; названия товаров Korzinka и пользовательские записи показываются так, как предоставлены источником или пользователем. Нет календаря платежей, полноценного сравнения альтернатив и учёта запасов при формировании списка. Офлайн PWA ограничена оболочкой: для работы с данными нужен сервер.

Это MVP для локального хакатона, не готовый к публичному развёртыванию: требуются HTTPS, безопасная настройка секретов, защита от перебора, аудит и политика хранения данных. Django admin доступен только персоналу. Для изменения каталога используйте админ-панель и указывайте достоверный источник, магазин и признак демонстрационной цены.

## Цены Korzinka

На странице цен показываются товары категории «Суперцены недели» из общедоступного каталога Korzinka для Ташкента и Ташкентской области. При посещении страницы сервер проверяет обновления не чаще одного раза в 6 часов (после ошибки повторяет через 30 минут). Сохранённые предложения отображаются с датой загрузки и сроком акции, если он указан источником. Предложения на упаковку не подменяют демонстрационные цены ингредиентов в расчётах меню. Добавленная в список покупок цена является снимком на момент добавления. Проверяйте условия, дату и наличие в магазине.

## AI-анализ расходов

На странице бюджета можно сохранить цель и запустить анализ расходов за текущий календарный месяц. До запроса интерфейс сообщает, что бюджет, суммы и категории расходов, до 15 названий покупок и цель будут переданы провайдеру `factory.marshub.uz`; пользователь должен отметить согласие. Финансовые итоги и срок достижения цели при указанном ежемесячном взносе рассчитываются на сервере. Это арифметический сценарий, не прогноз и не гарантия накопления.

Для работы функции установите на сервере `AI_BASE_URL=https://factory.marshub.uz/v1`, `AI_MODEL=gemini-2.5-flash` и `AI_API_KEY`. Ключ не должен попадать в Git или фронтенд. Если ключ не настроен, функция вернёт сообщение об этом; без расходов за текущий месяц анализ не запускается. Ответы модели могут содержать ошибки. Локальная симуляция в `postman/simulations/` воспроизводит совместимый формат API, но не проверяет реального провайдера или качество рекомендаций.

## Семья и копилки

В разделе «Семья» пользователь может создать одно семейное пространство и передать код приглашения другим зарегистрированным участникам. Код доступен только создателю; его можно обновить, чтобы отозвать старый. Участники могут выйти, после чего общие копилки им больше недоступны. Создатель пока не может передать владение или удалить семью через интерфейс.

В разделе «Копилка» доступны личные и семейные цели с историей пополнений и прогрессом. Каждое пополнение — только учётная запись, банковские операции и автоматическое списание из бюджета не выполняются. Свои ошибочные записи можно удалить; семейные записи видны членам семьи. Ранее сохранённая цель в бюджете отображается отдельно и автоматически не объединяется с копилками. Храните код приглашения приватно: любой обладатель кода сможет присоединиться к семье до его обновления.
